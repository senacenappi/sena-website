Edit your website

Add new works, change photos and statements, and update your About and Contact pages. Changes appear on the site about a minute after you save.

Open the editor →

Sign in the same way you did the first time (with GitHub, or with the email invitation). Bookmark this page so you can find it again.

Add a new work

  1. In the editor, open Works and add a new entry.
  2. Fill in the Title, Year, Medium and Dimensions.
  3. Set the Order. Works are shown from the lowest number to the highest. Using 10, 20, 30… makes it easy to put a new piece in between later.
  4. Drag in the Main photo, and any Detail photos (close-ups).
  5. Paste the Statement in English and 한국어. Leave an empty line between paragraphs.
  6. Press Save. Refresh the website after about a minute.

Change things later

  • Edit a work: open it under Works, change anything, then Save.
  • Move a work: change its Order number.
  • Take a work off the site: tick “Hide from the website”. It stays saved, so you can bring it back.
  • About, resume and contact: open “About and contact”. Add a resume section for each heading (Education, Exhibitions, Awards…).

Photos

  • Use JPG or PNG. Any size is fine; the site shrinks photos automatically.
  • iPhone photos are often HEIC, which won’t upload. Change Settings → Camera → Formats to “Most Compatible”, or export the photo as JPEG first.
  • Photos on a plain light background look best next to the others.

If something looks wrong

  • Wait a minute and refresh. Each save takes a moment to publish.
  • A work without a main photo doesn’t appear until one is added.
  • Every save is kept, so nothing is lost. Ask Kokikin to roll back if needed.

웹사이트 수정하기

새 작품을 추가하고, 사진과 작가노트를 바꾸고, About과 Contact 페이지를 수정할 수 있어요. 저장하고 1분쯤 지나면 사이트에 반영됩니다.

편집기 열기 →

처음과 같은 방법(GitHub 또는 이메일 초대)으로 로그인하세요. 이 페이지를 북마크해 두면 편해요.

새 작품 추가

  1. 편집기에서 Works를 열고 새 항목을 추가하세요.
  2. Title(제목), Year(연도), Medium(재료), Dimensions(크기)를 입력하세요.
  3. Order(순서)를 정하세요. 숫자가 작은 작품부터 보여요. 10, 20, 30처럼 띄워 두면 나중에 사이에 넣기 쉬워요.
  4. Main photo(대표 사진)와 Detail photos(디테일 사진)를 끌어다 놓으세요.
  5. 영어와 한국어 Statement(작가노트)를 붙여 넣으세요. 문단 사이에는 빈 줄을 하나 두세요.
  6. Save를 누르고, 1분쯤 뒤에 사이트를 새로고침하세요.

나중에 바꾸기

  • 작품 수정: Works에서 작품을 열어 고친 뒤 Save.
  • 순서 변경: Order 숫자를 바꾸세요.
  • 사이트에서 내리기: “Hide from the website”에 체크하세요. 저장은 그대로 되어 있어서 언제든 다시 올릴 수 있어요.
  • About, 이력, 연락처: “About and contact”를 여세요. 이력은 제목(학력, 전시, 수상…)마다 섹션을 하나씩 추가하면 돼요.

사진

  • JPG나 PNG를 사용하세요. 크기는 상관없어요. 사이트가 자동으로 줄여 줍니다.
  • 아이폰 사진은 보통 HEIC라서 올라가지 않아요. 설정 → 카메라 → 포맷에서 “높은 호환성”으로 바꾸거나, JPEG로 내보낸 뒤 올리세요.
  • 밝고 단순한 배경의 사진이 다른 작품들과 잘 어울려요.

문제가 생기면

  • 1분 정도 기다렸다가 새로고침하세요. 저장할 때마다 반영되는 데 잠깐 걸려요.
  • 대표 사진이 없는 작품은 사진을 추가해야 사이트에 나타나요.
  • 저장 기록이 모두 남아 있어서 사라지는 건 없어요. 되돌려야 하면 Kokikin에게 말해 주세요.
